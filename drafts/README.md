# Drafts

Generated Substack drafts, one folder per task, grouped by year:

```
drafts/<task-slug>/<YYYY>/<YYYY-MM-DD>-<title-slug>.md
```

Files here are **unpublished drafts for editorial review**. Nothing in this repo publishes to Substack.

Add drafts with `scripts/commit-draft.sh` (see `docs/commit-draft-workflow.md`) rather than by hand, so every draft is secret-scanned, named consistently, and committed on its own.
